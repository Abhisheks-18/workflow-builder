# FlowForge Workflow Builder

A visual workflow builder application developed as part of the FlowForge Enterprise Internship Assignment.

This application allows users to create trigger and action nodes, connect them visually, and manage workflow logic using a node-based UI.

---

## 🚀 Features

* Add Trigger Nodes
* Add Action Nodes
* Connect nodes visually
* Delete nodes (double click)
* Zustand state management
* Unique node IDs using UUID
* Interactive React Flow canvas
* Zoom / Pan support

---

## 🛠 Tech Stack

* React + TypeScript
* Vite
* React Flow
* Zustand
* UUID

---

## ▶️ How to Run

1. Clone repository

git clone https://github.com/Abhisheks-18/workflow-builder.git

2. Go inside project

cd workflow-builder

3. Install dependencies

npm install

4. Run project

npm run dev

Project runs at → http://localhost:5173
